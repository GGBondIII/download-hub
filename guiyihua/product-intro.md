# 产品介绍：数据归一化工具电脑可执行版

把杂乱数据整理成标准模板格式的工具，给企业里做财务和数据分析的人用，整理规则要对、不能丢数、不能编数。单机版，数据只在你这台电脑上，不联网、不往外传。

## 怎么用

双击 exe，会自动打开浏览器，出现五步向导：

1. **模板**：点“用示例模板”，或从 Excel 导入你的标准模板，工具照着它的第一行列名来整理。
2. **乱数据**：点“用示例数据”先试，或从 Excel、CSV 导入你的乱数据。原合计填原表里的总数。
3. **对列**：工具先按名字和财务常用叫法猜好了，你逐项确认，不对的下拉改过来。猜不出就选“（空着）”，那一列空着、不编数。
4. **清洗预览**：日期统一成 2026-11-09，金额只留纯数字，1.23 万元换算成 12300。红行就是转不出来的，点“改这行”改原值，改完相关格子和合计立刻跟着变。
5. **导出**：点一下导出，得到一个新 Excel，里面三张表：标准表、异常清单、原始与记录。

## 规则

- 日期多种写法（2026/11/9、2026-11-09、11月9日、20261109）统一成 2026-11-09；认不出的不编，标红。
- 金额去掉 ¥、元、逗号、空格留纯数字；1.23万元换算成 12300；一格混文字和金额会拆开；“—”“无”“N/A”和空统一当空，不写成 0。
- 公式按算出来的结果比对：客户等级（VLOOKUP）、是否超预算（IF）、合计（SUM）、办公费用合计（SUMIF）；合计会跟原合计单独核对。
- 只能算 VLOOKUP / IF / SUM / SUMIF；引用外部文件的公式算不出来，会标红让你在 Excel 里核对。
