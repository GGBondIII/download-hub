# 产品介绍 — 自建版 Telegram 登录码网站 v0.1

## 是什么

一个只给你一个人用的 Telegram 登录码接收页。

你自己的服务器上跑着一个 Telegram 客户端（Telethon，Telegram 官方 MTProto 协议），它以你本人的身份登录，专门监听官方账号 777000 发来的登录码。码一到，就显示在你自己的网页上，5 分钟过期自动清除。

## 解决什么问题

之前那个第三方同步页的问题是：

1. 会掉线 — 页面显示“接码设备已掉线”，码到了也看不到；
2. 会话在别人手里 — 你的 Telegram 登录状态在第三方的设备上，它出问题，你的码和账号都受影响；
3. 不知道它能稳定多久 — 没有自己的接收端，只能等它恢复。

自建版把接收端换成你自己的：监听、网页、令牌都在你手里，第三方掉线不影响你。

## 给谁用

只给这个 +57 号码的账号本人用。号码是实名注册在你名下的，装卡的手机在弟弟手里，短期内拿不回来 — 所以本期特意不依赖“手机在你手里”，只依赖“你自己的服务器一直在线监听 Telegram”。

## 怎么用（正常一次登录）

1. 在新设备上打开 Telegram，输入号码，点发送验证码。
2. 打开你自己的这个页面，粘贴访问令牌，点“刷新验证码”。
3. 5 分钟内把显示的 5 位码填回新设备，完成登录。

第一次部署时多一步：首次登录要一次短信码，需要弟弟那部手机上读一次、念给你，你在服务器终端输入。之后生成会话文件，一般不用再要短信码。

## 怎么部署

- 演示：`python3 app.py --demo`，打开 http://127.0.0.1:8766/ ，令牌在 `data/access_token.txt`。不连 Telegram，只看版式和流程。
- 真实：在 https://my.telegram.org 建应用拿 API_ID / API_HASH，按 `config.example.py` 复制出 `config.py` 填好，`pip install -r requirements.txt`，再 `python3 app.py`。
- 魔搭 Notebook：整个文件夹放 `/mnt/workspace`（只有这里重启后还在），同上安装、启动。**注意：Notebook 单次最长 10 小时、空闲超 1 小时自动关，关了服务就停了，得重开；放魔搭上做不到真正 24 小时稳定。** 保活在另一个旁聊里做，这里不重复做。

## 安全提醒（必读）

- 会话文件（`data/tg_session.session`）= 你的账号本身。别发给任何人，别上传到公开地方，只放服务器本地。
- 访问令牌（`data/access_token.txt`）= 这页的钥匙。别把带 `?token=…` 的链接发给任何人，别截图带令牌。
- 码 5 分钟过期，过期自动清除，只留最新一条，不留历史。日志不记码本身。
- 没有正确令牌查码返回 401，什么都不给；无码返回 404。
- 新 IP / 新设备登录，Telegram 可能还要短信二次验证或限流，这是正常的。

## 没做到和待验证的

- **不做通用短信。** 本期只收 Telegram 登录码，不收 Gmail、TikTok 的短信。那些短信是运营商只发到 SIM 卡上的，要收得另做短信转发，是下一期。
- **不保证 24 小时。** 魔搭 Notebook 有 10 小时 / 1 小时上限；Telegram 也可能对新服务器 IP 风控。
- **未验证：** 真实 Telegram 登录全流程（需要你自己的 API 凭证 + 一次短信码，在你自己的服务器上完成，我没有登录、没有发码）；魔搭上的长期在线表现；新 IP 下 Telegram 的验证表现。
