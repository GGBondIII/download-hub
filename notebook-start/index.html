打开 Notebook 页面去启动
  1. 点上面按钮，打开魔搭 Notebook 页面（要登录）。
  2. 找到 CPU 那一行（8 核 32G），点「启动」。
  3. 拖一下滑块验证，等它变成「运行中」就行。

先说清楚：这个页面不会替你自动启动，也绕不过登录和滑块验证，启动始终由你自己点。

CPU 实例单次最多跑 4 小时，到时间会停；超过 1 小时没操作也会自己关。提醒每小时检查一次，快到期或停了会发邮件到你的 163 邮箱。

不想再收到提醒：跟助手说一声「关掉 Notebook 提醒」就行。
