## 一、程序是什么

常熟站智考通是一站式备考系统：日常练习、模拟考试、正式考试、错题本与智能分析、
题目上报、考试管理、题库管理、用户管理、上报处理、统计分析、系统设置，12 个模块全齐；
v2.0 再并入刷题宝的个性化自适应、学习方法五环节、组卷模板、PDF 导入与图文配对、
题库质量闭环、简答批阅、学习计划、后台可视化仪表盘、跨主机联邦、运维备份、
本地 AI 辅助出题。

- **exe 版（主）**：桌面客户端，与原版同样是桌面 exe 程序。Python 3.4 + tkinter，
  便携文件夹 + 32 位启动器，XP / Win7 / Win10 通用（32 位与 64 位系统都能跑）。
- **网页版（辅）**：供别的系统使用，与 exe 版共用同一套服务器核心与数据模型。
- **服务器核心**：Python 标准库 + SQLite 单文件，零依赖、零 CDN，离线可用，
  端口 **8766**（与刷题宝的 8765 区分开，同一主机可同时跑）。API 共 107 个端点：
  v1 的 61 个 + v2 新增 `/api/v2/` 46 条。
- **数据**：SQLite 单文件 `data/zhikaotong.db`；首次启动自动建库并播种演示数据：
  4 个用户、20 道常熟边检通用样题（单选 8、多选 4、判断 4、填空 2、简答 2，
  题号 ZK001–ZK020，分类：基础法规 / 证件查验 / 口岸勤务 / 执勤规范）、
  2 场考试（已发布 1 场「常熟站 2026 年第一季度业务考核」，固定试卷 10 道题，
  时长 60 分钟，名单含 minjing / minjing2；草稿 1 场「执勤规范专项测试(草稿)」）。

## 二、两种部署

### exe 版（推荐，主机用）

1. 解压 `changshu-zhikaotong-v2.1-exe.zip`（全部英文文件名，Win7 自带解压可直接解），
   建议放在浅一点的目录，例如 `D:\常熟站智考通\`。
2. 双击 `changshu-zhikaotong.exe`（32 位启动器，无控制台窗口）。
   启动器只做一件事：找到同目录的 `python34\pythonw.exe` 与 `app\main.py` 并拉起应用，
   找不到会弹中文提示，不静默退出。
3. 应用启动后在后台起内嵌服务器（`http://127.0.0.1:8766/`），用演示账号登录即可使用。
   首次启动自动在 `data/` 下建库播种。
4. **局域网其他机器**：在同一台机器上也跑这个 exe，登录页把服务器地址改成主机 IP
   （例如 `http://192.168.1.100:8766`），即可连主机；主机 exe 不用额外配置。
   也可以直接用浏览器访问主机地址走网页版（见下）。

### 网页版（别的系统用）

1. 解压 `changshu-zhikaotong-v2.1-web.zip`，确认已安装 Python 3.4 或以上版本。
2. Windows 双击 `start.bat`；Linux / macOS 执行 `sh start.sh`；
   或直接 `python server.py`（端口可用环境变量 `ZHIKAOTONG_PORT` 改，默认 8766）。
3. 浏览器打开 `http://<主机IP>:8766/`；Lite 版（IE8 / XP 老浏览器）打开
   `http://<主机IP>:8766/lite`。
4. 局域网其他机器把地址栏的 `127.0.0.1` 换成主机 IP 即可访问。
   备份时把整个 `data/` 目录一起复制。

## 六、改名小工具（给别的站用）

exe 包内自带改名工具：`rebrand-tool.exe`、`rebrand.py`、`branding.json`
（都在 exe 文件夹根目录，与 `changshu-zhikaotong.exe` 并列）。
v2.0 已在完整交付树副本（exe/ + web/，/tmp 副本）上实测改名与恢复：
exe 包 49 个文件（全名 90 处、站名 9 处）、web 包 37 个文件（全名 73 处、站名 9 处），
12 个新增 v2 服务器模块与 3 个新客户端视图全部覆盖；改过一次后读当前名字可再改；
恢复用最近一次备份，52 个文件 0 缺失 0 错误，新旧 exe 不会同时存在。

1. **双击打开**：双击 `rebrand-tool.exe`。它只做启动：按顺序找 Python 3.4 运行时——
   同目录的 `python34\pythonw.exe`、系统 PATH 上的 `pythonw.exe`——然后启动同目录的
   `rebrand.py`，无控制台窗口。运行时找不到或 `rebrand.py` 缺失时会弹窗提示。
   也可直接用 `python34\pythonw.exe rebrand.py` 启动。
2. **确认目标文件夹**：默认取工具所在目录的上一级（即程序根目录）；
   点「浏览…」可改。扫描时递归该目录。
3. **确认当前名字**：「当前站名」「当前程序名」打开时已从 `branding.json`
   读入填好（只读）。工具本身不写死当前名字，改过一次还能再改
   （第二次打开显示的是当前名字）。
4. **填新名字**：「新站名」例如填 `南京站`；新程序名会自动按「新站名 + 智考通」
   填好（例如 `南京站智考通`），可再手动改。
5. **启动器 exe 改名**：勾选项默认勾上。改名后启动器 exe 文件名变成新程序名
   （如 `南京站智考通.exe`；原来英文名的 `changshu-zhikaotong.exe` 也会一起改）。
6. **扫描预览**：点「扫描预览」，逐行列出将要改动的文件（相对路径 + 全名出现次数 +
   站名出现次数），确认后再执行，不要静默改。
7. **一键改名**：点「一键改名」。执行前会用确认对话框把汇总（文件数、总处数、
   备份目录名）再给用户看一次，点确定才执行。
8. **改名后重启程序生效**：关闭智考通再重新打开，新名字才生效。
   正在运行的智考通请先退出再改名。

改名规则：先替换全名（当前程序名 → 新程序名），再替换站名（当前站名 → 新站名），
避免全名被站名替换拆散；只做纯文本替换，不改文件结构。
替换范围：exe 应用源码（`app/` 内 `.py` 的界面文案与配置）、网页版页面与配置
（`.py` / `.html` / `.js` / `.css` / `.sh`）、产品介绍与说明文档（`.md` / `.html` / `.txt`）、
GBK 编码的 `.bat`。
**不碰**：题库数据文件（`data/*.db`、`*.db`、`*.sqlite`）与题目内容；`backup-*/` 目录；
工具自己的目录；`__pycache__`、`.git`、图片/压缩包/办公文档等二进制文件。
**备份**：执行前自动把被改动的文件备份到程序根目录下的 `backup-<YYYYMMDD-HHMMSS>/`
（保留相对路径；同一秒内多次改名自动加 `-2`、`-3` 后缀，不会撞名），
备份里含一份 `restore-manifest.json`（恢复清单）和改名前 `branding.json` 的副本。
**恢复**：点「恢复备份」，选一个已有的 `backup-*/` 目录确认后一键拷回去；
恢复前会先把当前文件再备一份，防止恢复本身出错；恢复后 `branding.json` 回到改名前，
改过名的 exe 也会恢复原名（用最近一次备份恢复时，新旧两个 exe 不会同时存在；
若中间又改过一次名，请用最近一次备份恢复，或手动删除多余的 exe）。
改名只改程序名与站名这两个字符串；题库内容、账号、端口（8766）、版本号（v2.1）都不动。
改名后如需重新分发，请用改名后的源码重新打包（或直接分发便携文件夹）。
详细说明与自测记录见 `rebrand-tool/README.md`（改名工具源码目录）。

## 七、常见问题

- **Win7 / XP 上能跑吗？** 能。exe 版是 32 位启动器 + 32 位 Python 3.4.4 运行时，
  XP SP3 及以上、Win7（32/64 位）、Win10 都能跑；启动器只依赖 Windows 自带的
  KERNEL32.dll / USER32.dll / msvcrt.dll，无需额外运行库。
  网页版在 XP 上请用 Lite 版 `/lite`（IE8 兼容，降级点在页面底部明说：
  无圆角/阴影/毛玻璃/动效/深色模式/系统字体，大标题大按钮留白）。
  Lite 版新增三个轻量页：自适应练习（`/lite/practice`：五环节 + 自适应 + 薄弱项）、
  我的报告（`/lite/report`：练习统计表 + 简答批阅结果表）、学习计划（`/lite/plans`：
  文字进度条）；图表在 Lite 版一律降级为纯文本表格，无 SVG、无数字滚动、无动效。
- **端口被占用怎么办？** 默认端口 8766。网页版可用环境变量 `ZHIKAOTONG_PORT`
  改端口；exe 版内嵌服务器端口固定 8766，端口被占时请先关掉占用 8766 的程序
  （例如同时跑了网页版），再启动 exe。
- **首次启动建库**：首次启动自动建库并播种演示数据（4 用户 / 20 题 / 2 场考试），
  不用手动建库。数据库在 `data/zhikaotong.db`，备份时整个 `data/` 目录一起复制。
- **密码务必改**：演示账号密码均为 123456，上线前务必修改；学员注册邀请码初始值
  CS2026，管理员可在系统设置里随时更换。
- **题库导入模板**：在考官端「题库管理」里点「下载导入模板」拿 Excel 模板，
  按模板填好后导入；导入结果逐行列出成功与失败原因。Word 导入同样在题库管理里。
  PDF 导入在「导入任务」里，只做文字型 PDF，扫描型会明确拒绝。
- **组卷模板怎么开考？** 考官在「组卷模板」里新建模板（五题型配比，含简答、填空），
  点「按模板开考」即生成一场正式考试；学员在正式考试里参加，交卷后简答进批阅队列，
  考官在「简答批阅」里人工打分（≥60% 满分算对）。
- **改名后什么时候生效？** 改名后关闭智考通再重新打开，新名字才生效。
  正在运行的智考通请先退出再改名。
- **发现新版本提示**：登录页版本号上方会显示「发现新版本」+「立即更新」；
  客户端更新检查只查版本记录，不下载程序体，更新包由部署方另行分发。
- **联邦共享怎么用？** 管理员在「联邦共享」里登记对方主机（地址 + 端口 + 对方令牌），
  点「连通测试」看对方题库目录，点「拉取题库」按题号去重拉取；本机令牌在同一页查看，
  对方拉取本机目录时需带上本机令牌（`?token=…`）。
- **exe 双击没反应？** 先确认文件夹完整（`python34\pythonw.exe` 与 `app\main.py`
  必须在 exe 所在目录的固定相对位置，改名或挪动文件夹结构会导致中文提示报错）；
  启动器找不到文件时会弹中文提示，不静默退出。请把便携文件夹放在浅一点的目录
  （例如 `D:\常熟站智考通\`），超长路径不支持。

## 八、已知限制（请如实看待，不要当作已验证）

- **未在真实 Windows / XP 机上双击验证过。** exe 启动器与改名工具启动器只做了
  编译与 `file` / `objdump` / `strings` 静态核对；客户端界面只在 Linux + Xvfb 下
  用系统 Python 3.12 + tkinter 8.6 跑过自测；Python 3.4.4 运行时上的实际表现
  仅做了 3.4 语法静态检查。最终必须在真实 XP / Win7 机器上双击验证。
- **未做真实 150 并发与局域网多机测试。** 本次只做接口自测与小规模冒烟
  （单机 curl 抽查、干净库启动验证）；
  真实局域网多机访问与 150 并发需在真实环境核实。
- **浏览器实测未做**：现代版在 Chrome / Edge 中的实际交互、动效手感、深色模式切换、
  空格键推进；Lite 版在真实 IE8 / XP 机上的渲染。考试全流程的端到端浏览器走查
  （交卷、自评、阅卷回看）也未做——接口层已验证，页面逻辑按同一契约编写。
- **题图**：tkinter 原生只解 GIF / PPM，本客户端不内置图片解码；题图处显示文件名，
  点击放大弹窗说明文件位于服务器 `data/assets/`。Pillow 的 `_imaging.pyd`
  在真实 XP 上的实际加载与题图显示未验证。
- **部门横向对比与计划进度是 v2.0 新修的逻辑**：精确汇总与去重计数已在自测里用
  手工对照数验证过（见第五节末），但真实题库（几百道题）下的表现仍需上线后核对。
- 客户端更新检查只查版本记录，不下载程序体；更新包由部署方另行分发。
- 启动器不管应用死活：只负责启动后退出；端口占用、数据库损坏等问题由应用自己处理，启动器不重试、不兜底；启动器不含图标与版本信息。v2.1 起应用自己带启动失败兜底（写 `error.log` + 弹框），但启动器仍不重试。
