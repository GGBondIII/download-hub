# 刷题宝 v0.7 — 产品介绍（Win7 兼容修复版）

## 是什么

常熟边检站内部用的局域网离线刷题系统（v0.7 Win7 兼容修复版，Apple HIG 风格）。
一台性能好一点的电脑当主机，全站 Win XP / 7 / 10 电脑和其它系统网页共用同一套题库，不连互联网。
三种用法：主机上双击 exe 程序；或主机装 Python 后双击 start.bat；其他电脑一律用浏览器打开局域网地址。

一句话：平时练题、阶段考核、看个人和队报告、针对薄弱项再练，题库用 Excel / Word / PDF 带图导入、审核后发布新版本；简答题人工批阅、学习计划按人下发。

## 解决什么

- 以前题库散在各人手里的 Word / Excel 里，版本乱、图片丢、没法统一练。
- 练了不知道弱在哪：v0.4 给每个人算正确率、知识点掌握（Elo）和薄弱 TOP，自动组薄弱项训练。
- 阶段考核要统一计时、防断线、到时强制交卷，草稿存在服务端，断线能续答。
- 老机器不能掉队：XP 机走 Lite 版，同样能登录、练题、交卷、看报告。

## 给谁用

| 角色 | 能做什么 |
|---|---|
| 民警 | 练习、阶段考核、错题重练、薄弱项训练、我的报告；看不到别人明细和队报告 |
| 教官 / 队领导 | 上面全部 + 队报告、题库导入审核、发布新版本、回滚 |
| 管理员 | 全部 + 系统配置、备份、客户端更新（后续） |

## 怎么启动（主机那台电脑）

方式 A（推荐，不用装 Python；Win7 和 Win10/11 要分版本）：把整个 `mvp-v07` 文件夹拷到主机上，按系统选一个 exe（都在 `dist/` 里）：**Win7 SP1 64 位主机双击 `刷题宝-Win7.exe`**（Python 3.8 打包，Win7 专用）；**Win10 / Win11 主机双击 `刷题宝.exe`**（Python 3.12 打包，通用版）。两个版本功能完全相同，不要混用——通用版在 Win7 上双击会直接失败（v0.6 的通用版已在真实 Win7 机上试过，装不上）。启动后自动打开浏览器到本机地址；控制台窗口会打印本机地址、局域网地址和停止方法（关窗口即停止）。exe 是单文件程序，数据库和题库存在 exe 旁边的 `data/` 里。XP 不能跑任何 exe，XP 机走网页版 /lite。

方式 B（主机已装 Python）：Win7 主机只能装 Python 3.8（3.9 及以上装不上 Win7）；Win10 / Win11 主机装 Python 3.8 以上。安装时勾选 Add Python to PATH；离线安装包提前从能上网的电脑下载，U盘拷过来。把整个 `mvp-v07` 文件夹拷到主机上，双击 `start.bat`（Windows）或 `./start.sh`。不要和方式 A 同时开（会抢 8765 端口）。

启动后：本机打开 `http://127.0.0.1:8765/`；局域网其他电脑用 `http://<主机IP>:8765/`（启动窗口会打印，主机 IP 用 `ipconfig` 查，最好设固定 IP，防火墙放行 8765 端口）。XP / 老浏览器打开 `http://<主机IP>:8765/lite`。网页版说明（可交互演示）：`http://<主机IP>:8765/showcase.html`，或直接双击打开 `showcase.html`。

演示账号：`admin` / `jiaoguan` / `minjing` / `minjing2`，密码都是 `123456`，**上线前务必改掉，正式使用时删除演示说明**。

## v0.5 P1 新增了什么（相对 v0.4）

1. **图文错位自动修复**：导入 Excel / Word / PDF 时，图片不再只靠“挂在第几行”——系统按图片位置与最近题号的距离打置信度：紧挨着题干（0 行）97% 自动过，隔 1 行 85%、隔 2 行 72% 进复核，隔 3 行以上或找不到题号就进人工队列。复核页能看到题干、图片和置信度，可以换题、确认或驳回；每次导入都出一份配对报告（自动过 / 复核 / 人工各多少张），不谎称 100% 自动。
2. **PDF 文字型导入**：文字型 PDF 直接上传，系统本地抽文字、抽图、按坐标切题，进草稿 → 审核 → 发布，和 Excel / Word 走同一套流程。扫描型 PDF（纯图片页）不硬识别，上传时会明确说“扫描型需 OCR，后置”。
3. **简答 / 材料题批阅**：新增简答题和材料题（题干 + 参考答案 + 评分要点 + 满分）。民警在“简答”页写文字答案提交，教官/管理员在后台按评分要点打分、写评语；得分≥60% 满分算通过，不及格进错题本；得分进个人报告，和选择题分开列。系统不做自动批改。
4. **学习计划下发**：教官/管理员可以建计划（名称、目标知识点、每日题量、目标题量、截止日），下发到一个部门或一个人。民警在“我的报告”里看到自己的计划和进度（已做/目标、百分比、还剩几天、是否逾期）；到期没做完的计划进后台预警。Lite 版也有文字版计划列表（/lite/plans）。

## v0.7 Win7 兼容修复了什么（相对 v0.6）

1. **Win7 专用 exe**：`dist/刷题宝-Win7.exe`，Python 3.8 + PyInstaller 5.13.2 打包，Win7 SP1 64 位能用。v0.6 通用版内嵌 Python 3.12，官方不支持 Win7，已在真实 Win7 机上试过、确实装不上（详见 `audit-win7-compat-v0.7.md`）。
2. **压缩包全英文文件名**：v0.6 的 zip 里 15 个中文文件名没有置 UTF-8 标志，Win7 自带解压按 GBK 解码，其中 4 个文件名含非法 GBK 字节序列，直接报“解压缩损坏”。v0.7 的 zip 已全部改成英文文件名，Win7 自带解压可用。
3. **start.bat / build_exe.bat 改 GBK 编码**：去掉 `chcp 65001`（Win7 命令行下会扰乱批处理解析），中文提示不再乱码；没装 Python 时明确告诉用户改用 exe。
4. 功能与 v0.6 完全相同，只改兼容性。

## v0.6 P2 新增了什么（相对 v0.5，最终版）

1. **跨主机题库共享（联邦）**：同一局域网里，兄弟站的题库也能拉过来用。不直接裸连：后台“跨主机题库共享”里登记对方主机（站名、IP、端口、共享令牌），测试连通后拉取；只开放题库目录，不开放成绩/密码；共享包带 SHA-256 哈希，验不过就拒绝导入；拉回的题先按内容哈希去重，再进草稿 → 审核 → 发布，不直接覆盖本站题库；取题记审计（谁、什么时候、从哪台主机拉了几道题）。对方主机也要开着服务、配好共享令牌（本站令牌在后台“查看本站共享令牌”里看）。
2. **运维备份自动化**：后台“运维备份”里一键备份（数据库 + 题库附件，打成带时间戳的 zip，可下载）；每天自动备一份（服务器开着时），保留最近 7 份，旧的自动清理；恢复只能管理员做，恢复前先自动再备一份当前库防丢，恢复后列表把磁盘上的备份重新扫回来；没有自动删库。Lite 版后台总览也有备份与联邦摘要。
3. **本地 AI 辅助出题（规则变式）**：后台“本地 AI 辅助出题”里对已发布的选择/判断题生成变式——选项顺序打乱、题干同义词替换、题干数字替换（只改可替换槽位，不改考点）；变式先进草稿，须人工审核通过才能发布，数字变式须复核数字合理性；不联网、不接外部模型、不装大模型、不谎称 LLM 生成。每道题还有“易错点提示”（按全站作答统计：正确率、最常见错误答案），没作答数据时明说“暂无作答数据”。
4. **水印/脱敏砍掉**：按用户决定不做——局域网内自家题库、自己管理，无涉密风险。

## v0.4 P0 新增了什么（相对 v0.2）

1. **个性化自适应**：系统会看你每个知识点的最近表现，薄弱的自动多练、已掌握的少练、难度跟着你走（连对变难、连错变简单）；前 20 题数据不够时先按默认比例，页面上会写“样本不足”。
2. **学习方法五环节**：练习页改成五个入口——顺序练习打基础、随机测验练提取、错题回顾按 1/3/7/14 天到期排、薄弱分析看雷达、阶段考核检验。每题答完先闭卷再看解析，解析后会提醒你想一想“为什么错选项错”。
3. **后台管理**：教官/管理员多了一个“后台管理”页：全站总览、近 14 天趋势、部门横向对比、知识点热力、预警（7 天没练、正确率下滑、全部门某知识点低于 60%）、点人名看个人。民警只能看自己，查看个人明细会记审计。XP 的 Lite 版也有后台总览文字版。
4. **题库质量闭环**：全站都错或全站都对的题会自动标“疑似错题”待复核，不再放进薄弱训练；教官可以在后台停用或恢复。
5. **组卷模板**：教官可以按知识点配比和难度分布存一个模板（如证件查验 3:2、难度 1/2/3 按 2:3:3），下次考核直接按模板抽题；交卷后能打开打印版成绩单。

## v0.4 视觉升级新增（相对 v0.3）

1. **报告仪表盘**：个人报告、队报告、后台总览全部从“数字+简单表格”升级为可视化仪表盘。顶部数字卡带数字滚动动画（0→目标值，600ms 内完成，可打断）；五种图齐全——雷达图（知识点掌握度）、趋势折线图（近 14 天正确率/作答量）、柱状图（各知识点作答与正确）、热力图（部门×知识点掌握度，低于 60% 标红）、环形图（题型/难度占比，可点按题型/按难度切换）。全部内联 SVG + 原生 JS 手写，零 CDN、离线可用；图表有悬停提示、空状态、图例和单位；颜色用 HIG 系统色；深色模式跟随系统。没作答时不造假数据，显示空状态提示先练题。
2. **报告动效**：弹簧轻动 cubic-bezier(.34,1.56,.64,1)，200–350ms；卡片依次入场，每张延迟 60ms，可打断；图表生长/描绘入场；系统开“减弱动态效果”时全部瞬间显示，无动画；考核页默认减动效不变。
3. **答题动效与画面细节**：选项选中带 220ms 弹簧轻动与高亮；提交后对错反馈带 220ms 轻动，正确答案行高亮；题目卡片依次入场（每张延迟 60ms，可打断）；交卷成功带轻动 Toast，得分数字滚动；题目图片加圆角与阴影、留白加大；考核页默认减动效。
4. **Lite 版降级点（明说）**：Lite 报告不做动画图表，改文字版 + 简单条形（用 div 宽度表示正确率），后台总览同样有部门条形版；其余 Lite 降级点不变（G5–G10）。

## 怎么用（六个流程）

1. **登录**：输入账号密码登录。登录页只留账号、密码、登录按钮，演示账号收到折叠帮助里。
2. **练习**：点“开始练题”直接做题；想按知识点或科目练，展开“筛选条件”。答完马上看到对错、正确答案和解析，错题自动进错题本。
3. **薄弱项训练**：按你的掌握度自动组卷，默认薄弱 50% / 复习 30% / 新题 20%，比例可以改。
4. **阶段考核**：设题数和限时，点“开始考核”。服务端计时，题序和选项已打乱；每题点“保存草稿”；到时自动交卷，未答按错算。考核时动效已减到最少，不干扰答题。勾选“包含简答题”可把简答题也放进卷子：文字作答、人工批阅，不计入自动分，交卷后显示“待批阅”道数。
5. **看报告**：“我的报告”看数字滚动卡片、雷达、趋势、柱状、热力、环形五种图和知识点明细，可导出 CSV；“队报告”看全队汇总、高频易错题和本队热力；“后台管理”看全站趋势、部门横向对比、知识点×部门热力。
6. **题库导入（教官/管理员）**：三步——上传 Excel / Word / PDF → 审核通过 → 发布新版本。逐行校验，错的行进待修队列，不整批失败；Excel / Word / PDF 带图按位置打置信度配对，≥90% 自动过，其余在“图文配对复核”里确认；发布后可一键回滚，作答绑定版本号。模板在 `import-templates/` 文件夹。
7. **简答批阅（教官/管理员）**：后台“简答批阅队列”里看到民警提交的文字答案、参考答案和评分要点，填分、写评语提交；已批过的不能重复批改。
8. **学习计划（教官/管理员下发，民警查看）**：后台“学习计划下发”里建计划、选部门或个人、下发；民警在“我的报告”里看进度，Lite 版在 /lite/plans 看文字版。

## 设计上有什么不一样（v0.4 相对 v0.1）

按 Apple HIG 重做，检查表见 `design-checklist-HIG.md`：
- 大标题 + 分段控制导航，题目是视觉中心，筛选收起；苹方 / SF Pro 字体栈（离线不拉外部字体），系统语义色，8pt 间距，卡片圆角 16，按钮最小 44px。
- 没有浏览器原生弹窗，报错和确认都用应用内弹窗 / Toast，文案讲清后果。
- 动效只在切换、反馈、弹窗时出现，200–350ms 弹簧曲线，可打断；系统开“减弱动态效果”时全部瞬间切换；考核页默认减动效；倒计时每秒平滑走字。
- Lite / XP 版也重做了：在 IE8 / Chrome 49 能解析的范围内尽量接近——大字号标题、大按钮、留白、卡片分隔；做不到的已明说：无圆角、无阴影、无动效、无深色模式、无分段控制（详见检查表 G5–G10）。

## 注意事项

- 试题不离开局域网；导入文件只在主机上解析；备份用后台“运维备份”（`data/backups/`），也可以直接复制整个 `mvp-v07` 文件夹（主要是 `data/shuati.db` + `data/assets/`）。
- 内置 20 道样题是通用脱敏演示题，仅供练手，请以正式法规 / 教材为准，不要直接当正式题库用。
- 停止：启动窗口按 Ctrl+C。

## 没做到 / 待验证

- 未做：150 并发实机压测（只做过本机模拟）、双人确认发布、灰度发布、PDF 报告、账号批量导入、扫描型 PDF 的 OCR、激励提醒、全文检索与知识图谱。
- 刻意不做：水印/脱敏（用户决定：局域网内自家题库、自己管理，无涉密风险）。
- P1 已做但有边界：PDF 只认文字型，扫描型需 OCR（后置）；图文配对不是 100% 自动，低置信度要人复核；简答题不自动批改，只人工批；学习计划进度按“作答题数”算，同一题重复做会重复计（目标题量按题次计）。
- P2 已做但有边界：联邦共享要求两台主机同时开着服务、配好令牌；每日自动备份只在服务器开着时跑，关机期间不补；恢复会用备份内容覆盖当前数据库和附件（恢复前已自动备一份当前库）；变式只支持选择/判断题，简答题不支持；数字变式须人工复核合理性。
- 部门横向对比柱状图的答对数是推算值（总作答×平均正确率，误差≤1 道），非精确汇总。
- 待验证：真实脱敏样张（Excel / Word 各一份）还没拿到，导入只用自制样题验过；真实局域网多机、真实 XP 机开 Lite 页、150 并发、联邦共享两台真机，都要在真实环境再验一遍；浏览器实测动效手感与减弱动效切换未做。Windows exe 双击：v0.6 通用版已在真实 Win7 机上试过、装不上（原因见审核报告）；v0.7 Win7 专用版只在 wine 下验过，仍需在真实 Win7 机上双击验一遍；通用版也需在真实 Win10/11 机上验一遍。
- 深色模式：现代版已支持跟随系统；Lite 版不支持（IE8 无此能力，已在检查表写明）。
- exe 说明：两个版本，功能相同，不要混用。Win7 专用版 `dist/刷题宝-Win7.exe`（Python 3.8 + PyInstaller 5.13.2 打包），Win7 SP1 64 位用；通用版 `dist/刷题宝.exe`（Python 3.12 + PyInstaller 6.22.3 打包），Win10/11 用。v0.6 只有一个通用版，已在真实 Win7 机上试过、装不上；v0.7 的 Win7 专用版只在 wine 下验过（根页/Lite/showcase 均 200、登录通过，见 acceptance-v0.7.md），拿到真实 Win7 主机后请先双击验证一次。XP 不能跑任何 exe，XP 机走网页版 /lite。
