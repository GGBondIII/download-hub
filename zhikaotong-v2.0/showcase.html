两种部署

exe 为主，网页版为辅

同一套服务器核心与数据模型，端口 8766。主机用 exe，别的系统用网页版。

主 · 桌面客户端

exe 版 — XP / Win7 / Win10 通用

便携文件夹 + 32 位启动器，自带 32 位 Python 3.4.4 运行时与 Pillow，解压即用。

  1. 解压 changshu-zhikaotong-v2.0-exe.zip（全部英文文件名），建议放在浅目录，如 D:\常熟站智考通\。
  2. 双击 changshu-zhikaotong.exe，无控制台窗口，自动拉起应用与内嵌服务器。
  3. 用演示账号登录（见下方账号表）。首次启动自动在 data/ 下建库播种。

局域网其他机器：同样跑这个 exe，登录页把服务器地址改成主机 IP（如 http://192.168.1.100:8766），即可连主机。

辅 · 供别的系统使用

网页版 — 浏览器打开即用

与 exe 版共用同一套服务器代码，现代版 + Lite 版（IE8 / XP 老浏览器）双界面。

  1. 解压 changshu-zhikaotong-v2.0-web.zip，确认已安装 Python 3.4 或以上。
  2. Windows 双击 start.bat；Linux / macOS 执行 sh start.sh；或直接 python server.py。
  3. 浏览器打开 http://<主机IP>:8766/；Lite 版 http://<主机IP>:8766/lite。

端口可用环境变量 ZHIKAOTONG_PORT 改，默认 8766。备份时整个 data/ 目录一起复制。

考官 · 组卷批阅

组卷模板 + 简答批阅 + 质量闭环

模板按五题型配比（含简答、填空）开考，交卷后简答进批阅队列；人工打分，≥60% 满分算对，与选择题分开列示。

题库质量闭环：疑似错题标红，停用后不再出题，可恢复。PDF 文字型导入 + 图文错位自动配对（≥90% 自动 / 70–90% 复核 / <70% 人工）。

仪表盘 + 学习计划 + 联邦 + 备份 + AI 变式

仪表盘：雷达 + 趋势 + 柱状 + 热力 + 环形五图（纯 SVG），数字滚动 + 弹簧轻动；部门对比用精确汇总，不再推算。

给别的站用

改名小工具，一键换站名

exe 包内自带 rebrand-tool.exe（双击打开），把「常熟站智考通」换成别的站名。 工具读当前名字、不写死，改过一次还能再改；执行前自动备份，可恢复。

八步用法

  1. 双击打开 rebrand-tool.exe（无控制台窗口；找不到运行时会弹窗提示）。
  2. 确认目标文件夹：默认取工具所在目录的上一级（程序根目录），可点「浏览…」改。
  3. 确认当前名字：从 branding.json 读入填好（只读）。
  4. 填新站名：如 南京站，新程序名自动填好为「南京站智考通」，可再手动改。
  5. 勾选启动器 exe 改名（默认勾上）：改名后启动器 exe 文件名变成新程序名。
  6. 点「扫描预览」：逐行列出将要改动的文件，确认后再执行。
  7. 点「一键改名」：确认对话框再看一次汇总（文件数、总处数、备份目录名），点确定才执行。
  8. 改名后重启程序生效：关闭智考通再重新打开；正在运行的请先退出再改名。
